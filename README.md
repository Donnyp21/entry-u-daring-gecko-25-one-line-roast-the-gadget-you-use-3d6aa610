# entry-u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610 — One-Line Roast: The Gadget You Use Every Day

One roast for make.fun's "One-Line Roast: The Gadget You Use Every
Day" bounty.

> My phone autocorrects 'on my way' to 'on my way!' so I arrive everywhere sounding far more excited than I actually am.

Why it should land: a concrete detail about how the thing actually
behaves (autocorrect adding an exclamation mark), a fresh angle
rather than the battery complaint everyone makes, and the sting in
the last few words. One sentence, 118 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only, no network, no
randomness) writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the
competition's gate itself: one sentence, 1–200 characters. The roast
is a fixed string, so two runs produce identical bytes.
